FAQ

Frequently asked questions about Haltian ENTRYWAY people counting, installation, connectivity, data access, and privacy.

This FAQ answers common questions about Haltian ENTRYWAY. For step-by-step diagnosis of counting, connectivity, and battery issues, see Troubleshooting.

Product Basics

What is Haltian ENTRYWAY?

Haltian ENTRYWAY is a wireless, privacy-first people-counting sensor based on patented bi-directional 3-PIR detection. It counts directional movement through doorways and passages, reporting entries and exits without cameras or personal data collection.

How is ENTRYWAY different from a Presence sensor?

ENTRYWAY measures directional movement: how many people enter and exit a space. A Presence sensor reports binary occupancy: whether a space is occupied or unoccupied.

Use ENTRYWAY when you need people-flow data or occupancy estimation based on entries and exits. Use Presence when you need binary occupancy detection.

Does ENTRYWAY count people or movement?

ENTRYWAY records directional passages as entries and exits. Each complete passage through the three PIR detection zones contributes to the relevant count.

For example, when one person enters and then leaves five times, the sensor records five entries and five exits. The sensor does not identify or track individuals.

Accuracy And Measurements

How accurate is ENTRYWAY?

With correct installation and single-file traffic, ENTRYWAY provides more than 95% counting accuracy. Accuracy can be reduced by side-by-side passage, incomplete passage through the detection zones, high ambient temperatures, or unsuitable passageway dimensions.

See Operation and Troubleshooting for accuracy requirements and corrective actions.

Occupants Count And Occupancy Status

Does ENTRYWAY provide an occupants count directly?

No. An individual ENTRYWAY sensor reports only directional movement: entries and exits since its last report. It does not produce an occupantsCount measurement itself.

To calculate the current number of occupants in a space, create a Device Group and add the ENTRYWAY sensor or sensors that monitor that space. The Occupancy Data Engine then processes the member sensors’ events and publishes occupancy measurements under the Device Group’s UUID.

See Device Groups and Occupancy Data Engine.

How do I set up occupants count for a room?

  1. Create a Device Group representing the room or other monitored space.
  2. Add each ENTRYWAY sensor that monitors an entrance or exit of that space.
  3. Install the Device Group in the relevant space in the hierarchy.
  4. Configure the group’s inactivity period to match how the space is used.
  5. Query or subscribe to the Device Group’s occupantsCount measurement.

For an Entryway-only Device Group, the engine calculates:

occupantsCount = total entries - total exits

For example, a room with two doors needs both ENTRYWAY sensors in the same Device Group so the calculation includes movement through either door.

See Sensor Composition for supported combinations and Data Output for ENTRYWAY source measurements.

Should I add a Presence sensor to the Device Group?

For more reliable occupancy status, add one or more compatible Presence sensors to the same Device Group.

ENTRYWAY sensors provide directional people counts. Presence sensors confirm whether the space is occupied. Together, they provide:

  • occupantsCount calculated from Entryway entries and exits
  • occupancyStatus validated by both people-counting and presence events
  • Better correction of count drift when a sensor misses a passage

This mixed composition is particularly useful for larger rooms, spaces with multiple entrances, or rooms where people may remain still for long periods.

See Mixed Entryway and Presence groups.

How does the inactivity reset work?

Each Device Group has a configurable inactivity period. The Occupancy Data Engine uses it to correct count drift that can accumulate when an entry or exit is missed.

For an Entryway-only group, the engine resets occupantsCount to 0 after all Entryway sensors have been inactive for the configured period.

For a mixed Entryway and Presence group, the reset occurs only when all Presence sensors report no occupancy and no movement, and no sensor has reported activity during the configured period. The reset sets occupantsCount to 0 and occupancyStatus to not occupied.

Choose an inactivity period that matches the space. A period that is too short can reset a count while a quiet meeting is still in progress; a period that is too long allows count drift to persist longer.

See Reset Logic.

Installation And Placement

Where should ENTRYWAY be installed?

Install ENTRYWAY at doorways, corridors, staircases, and other defined passage points. The sensor supports passages up to 1600 mm wide and installation heights up to 2800 mm; the recommended installation height is 2500 mm.

For a doorframe installation, mount the sensor centered and within 1 cm of the bottom edge of the doorframe. For corridors without doorframes, use the ceiling installation method.

See Installation for the complete placement and mounting requirements.

Does every door need an ENTRYWAY sensor?

Install a sensor at each passage where you need directional counting. For a space with multiple monitored entrances and exits, cover each relevant passage to obtain representative people-flow data.

Can a door cause false counts?

Yes. Mount ENTRYWAY on the side opposite the door swing. A door that moves toward the sensor can trigger false counts. Keep the detection area clear of heat sources, lighting fixtures, and other obstructions.

See Installation for doorframe placement requirements.

Power And Connectivity

How is ENTRYWAY powered?

ENTRYWAY uses two user-replaceable AA alkaline batteries. No external power is required for standard operation.

What is the expected battery life?

Battery life is up to four years with the default configuration. Actual battery life depends on reporting frequency, mesh routing activity, and environmental conditions.

See Specifications for battery details.

How does ENTRYWAY communicate?

ENTRYWAY communicates through a Wirepas Massive mesh network to a compatible gateway. The gateway forwards sensor data to Haltian IoT.

Plan the mesh network so that devices have reliable coverage. The installation guidance recommends less than 20 m between mesh nodes or between a node and gateway.

Is the gateway tied to a specific mobile operator?

No. Haltian gateways use SIM connectivity with roaming, so they can connect through an available supported mobile network rather than being tied to one fixed operator.

Data Access And Integrations

How can I access ENTRYWAY data?

ENTRYWAY data is available through the Haltian IoT Platform:

  • MQTT Stream API for live measurement events
  • Service API (GraphQL) for current and historical measurements
  • Data API for exported data used in batch reporting and analysis

The primary ENTRYWAY measurements are entries, exits, and battery percentage. See Data Output for payloads and API examples.

Can ENTRYWAY integrate with third-party platforms?

Yes. You can use ENTRYWAY measurement data in supported third-party integrations through the Haltian IoT Platform.

Examples include workplace and smart-building platforms such as Cisco Spaces and Humly. See Integrations for the current list of available integrations, their requirements, and supported measurements.

Configuration

How do I reverse the entry and exit direction?

Use the people-counting orientation setting to reverse the direction when entries and exits appear inverted.

For Haltian IoT, see Configuration Commands. For self-hosted Wirepas gateways, use the People Counting Configuration command (tsmId: 17220) on endpoint 21/21:

  • peopleCountingOrientation: 0 uses the normal factory direction.
  • peopleCountingOrientation: 1 reverses the entry and exit assignments.

See CBOR Downlink Commands for the raw message format.

Privacy And Compliance

Is ENTRYWAY privacy-safe?

Yes. ENTRYWAY uses passive infrared detection and does not use cameras or capture images. It records anonymous directional counts without collecting personally identifiable information.

What certifications does ENTRYWAY have?

ENTRYWAY is documented as CE, RoHS, and RCM compliant. Contact Haltian before deployment when you need confirmation of market-specific approvals.
