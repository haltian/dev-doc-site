AI-Ready Data, Open Formats

Haltian IoT data is delivered in open, standard formats designed for direct use with modern tools — including AI assistants like ChatGPT, Claude, GitHub Copilot, and automated pipelines.

FormatUsed ForWhy It’s AI-Friendly
Apache ParquetHistorical data (Data API)Column-oriented, self-describing schema — AI tools read it natively
GraphQLLive queries (Service API)Typed, introspectable — AI can generate queries from natural language
MQTT + JSONReal-time streams (Stream API)Structured payloads — easy to parse, filter, and react to programmatically

No proprietary SDKs or locked ecosystems. Load Parquet files in Python, R, DuckDB, or Power BI. Query GraphQL from any HTTP client. Subscribe to MQTT from any language.

Try it with AI

Each demo below includes AI guidance — prompts and context you can copy into your preferred AI assistant to explore the data further, build visualizations, or generate integration code.

What You Can Do

  • Ask questions in natural language — “Show me the busiest meeting rooms last week” → AI generates the Parquet query
  • Build dashboards — Feed Parquet data into Power BI, Jupyter, or Observable notebooks
  • Create automations — Use MQTT streams to trigger alerts, log events, or feed ML models
  • Generate integration code — Describe your target system and let AI write the connector
